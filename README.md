# GAON · Windows 클라이언트

Windows 10/11 x64용 사내 검수 프로그램입니다. 업무 데이터·고객 자료·API 키·ERP 서버 소스는 이 공개 저장소에 포함하지 않습니다.

## 받기

설치 파일 `GAON-ERP-Setup-x64.exe`는 [릴리즈 목록](https://github.com/hykeelson/GAONERP-releases/releases/latest)에서 받습니다. 한 번 설치하면 이후 버전은 자동으로 업데이트됩니다.

## 설치와 로그인

1. 안내받은 `GAON-ERP-Setup-x64.exe`를 설치하고 **GAON ERP**를 엽니다.
2. 첫 화면에서 **Google 직원 계정으로 로그인**을 누릅니다. 따로 입력할 주소나 설정은 없습니다.
3. 기본 브라우저에서 관리자가 등록한 Google 계정으로 로그인합니다.
4. GAON 프로그램으로 돌아오면 직원 권한에 맞는 업무가 표시됩니다.

ZIP은 폴더 전체를 풀고 실행하세요. 설치본은 코드 서명이 없는 검수용으로 게시자 확인 안내가 나타날 수 있습니다. 운영 직원 PC의 보안 설정 변경은 담당자와 확인하세요.

로그인 갱신 정보는 Windows 사용자 계정의 보안 저장소로 암호화됩니다. 비밀번호·인증 토큰을 업무 화면에 넘기지 않습니다. 로그아웃하면 앱 알림과 저장한 로그인 정보가 정리됩니다. 실제 문자 발송·은행 지급은 별도 운영 연동과 승인이 필요합니다.

## 업데이트

| 무엇 | 어떻게 바뀌나 |
|---|---|
| 업무 화면 | 서버에서 바로 바뀝니다. 작성 내용을 저장하고 **보기 → 새로고침**하면 최신 화면입니다 |
| 프로그램(로그인·알림·창) | 설치본이 시작 10초 뒤와 4시간마다 이 저장소의 최신 릴리즈를 확인해 뒤에서 내려받습니다. 다 받으면 「지금 다시 시작 / 나중에」를 묻고, 나중에를 고르면 앱을 끌 때 바뀝니다 |
| ZIP 판 | 자동 업데이트를 하지 않습니다. 설치본(`GAON-ERP-Setup-x64.exe`)으로 바꿔 주세요 |

- 릴리즈의 `latest.yml`, `GAON-ERP-Setup-x64.exe.blockmap` 은 자동 업데이트에 쓰이는 파일입니다. 지우지 않습니다.
- 공개(Publish)된 릴리즈만 퍼집니다. 초안·사전 공개(pre-release)는 설치된 앱이 받지 않습니다.
- 관리자가 업데이트를 잠시 끄려면 PC 환경 변수 `GAON_DISABLE_UPDATES=1` 을 설정합니다.
- 맥 자동 업데이트는 애플 서명·공증이 준비되면 켭니다.

## 검증 범위

GitHub Windows 환경에서 가짜 자료의 인증·권한·세션 검사, 첫 실행과 IPC 경계, 패키지 포함 파일 검사, 설치·창 실행·제거, SHA256과 서명 상태 기록을 수행하도록 구성했습니다. 이 검사는 실제 직원 계정의 업무 저장·OS 알림 수신을 대신하지 않습니다. 고객 PC의 실제 로그인·업무·새로고침·알림 검수 결과는 릴리즈별로 별도 기록합니다.

Mac은 제작자 검수에만 사용하며 고객용 배포 대상은 Windows입니다. 모바일 iPhone/Android 앱은 별도로 준비합니다.

## 이번 검수 순서

1. 설치 후 직원 Google 로그인 → 건물 목록 확인 → **보기 → 새로고침** 후 로그인 유지 확인.
2. **도움말 → 가온봇 경량 분류 검수**를 켜고 오른쪽 가온봇을 엽니다. 검수 설정 변경은 화면을 새로고침하므로 입력 중인 내용을 먼저 저장하세요.
3. TEST 자료로 “TEST 건물 도배비 5만원 지출 요청해줘” 등을 입력합니다. 업무 제안 선택 후 대상·금액을 확인합니다. 분류는 이 PC에서 실행하며 서버의 직원 권한과 확인 단계는 유지됩니다.
4. TEST 작업의 비고·사진을 저장하고 새로고침해 보존 여부를 확인합니다. 실제 문자·송금은 이번 검수에 포함하지 않습니다.

경량 분류는 확신이 낮으면 제안하지 않습니다. 이 메뉴는 이번 실행에서만 적용하며 앱 재시작 후에는 다시 켜세요. 분류만으로 업무가 자동 실행되지는 않습니다. 업무 조회·저장은 인터넷 연결이 필요합니다.
